# XY 生意档案表

> 第一次用 XY 操盘系统，把这张表填了贴给教练（`/xy-coach`），能填几格填几格——**空着也行，看不懂的格子直接跳过**。填了的永不再问。更推荐的方式：直接跟教练聊天，它会像朋友一样问你。

```
【XY 生意档案表】（能填几格填几格，不确定就空着；每格括号里是填法例子）
1. 你/公司叫什么：______（例：老王 / 杭州某某贸易公司）
2. 做什么生意：______（例：卖袋泡养生茶 / 开了两家瑜伽馆 / 建材批发）
3. 卖什么、多少钱一单：______（例：养生茶 300 元一个月的量；第一次买的人多半先买 99 元三日装）
4. 客户从哪来：______（例：小红书 / 抖音 / 老客介绍 / 线下到店）
5. 现在手里有多少客户：______（例：微信好友 800，真正买过的约 120）
6. 一个月大概卖多少：______（例：40 单，1 万 2 左右）
7. 几个人在干、怎么分钱：______（例：就我自己 / 5 个人，提成 10 个点；没团队填"无"）
8. 最头疼的一件事（用你自己的话说）：______
9. 这个月最想达成什么：______（例：复购做到 20 单）
10.【内行选填，看不懂直接空着】首单转化率 ____%｜复购率 ____%｜升单率 ____%｜平均获客成本 ____元/人｜平均每个客户月贡献 ____元
```
