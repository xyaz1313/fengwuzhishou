#### 模板 F：大健康 / 先教育后直营（需要教育、重服务、后端赚钱）

与模板 A（减脂/体重管理）同属"需要教育+需要重服务"一类，价格阶梯、复购逻辑、订单粉打法高度共用，差异集中在体系选择和账号结构，以下只列 F 独有的部分，价格阶梯与复购数字直接参照模板 A，不重复列。

| 维度 | 打法 |
|---|---|
| 关键卡点 | 教育——大健康/药食同源很难在纯电商卖好，因为电商完成不了人与人之间的教育（参考 XY-DY-271）；千人一方先打开市场做认知，信任建立后再过渡到高客单一人一方（参考 XY-DY-270） |
| 适不适合你 | 高利润、需要教育、需要重服务的品，服务过程本身会建立信任带来复购，适合先做后端（参考 XSP-019）；新人优先选无需教育的品，大健康要从 0 做用户教育对新人不友好（参考 XY-DY-141）；一级类目只能做曝光，成交要细到四五级类目（参考 XY-DY-156）；看产品背后有没有知识/服务体系，传统保健品信息差已抹平（参考 XY-DY-160）；**这张模板的核心不是"一上来就直营"——需要教育的产品更适合先靠直销/微商团队做 2–3 年市场教育，等市场对产品有认知后再回捞直营逻辑，直接上直营很难成交（参考 XPP-003），模板名里的"直营"指的是这个回捞终点，不是起点** |
| 内容职能 | 垂直选题可占 70% 甚至更高（参考 XY-MA-133）；前端货盘与后端货盘按同一套"问题→方案"关联（参考 XY-DY-025）；无资质不讲功效，只做科普/个人经验（参考 XY-MA-1255） |
| 产品分层 | 价格阶梯参照模板 A（69 元体验装起，参考 MSP-002）；"新人礼"解决跳级脱节，只适用于带强服务体系的品（参考 XY-DY-178） |
| 获客导流 | 订单粉逻辑参照模板 A（参考 XY-DY-093 XY-DY-084）；实体：低价体验到店即完成筛选，再私域承接（参考 SCP-050 XY-DY-084）；百果园是实体直营基因做私域的样板——客户进店消费加微信，再靠客户完成社区团购拼单、分发销售送货，全国可查证（参考 RZP-011） |
| 成交场景 | 前端直播几乎不赚钱，利润在后端（参考 XY-DY-027）；复购率参照模板 A；个人微信真正能成交沟通的 200–1000 人，看触达成交率不看好友数（参考 XY-DY-113）；升单可到"消费型股东"（参考 CPP-040） |
| 直营 vs 微商 | 直营是卖货逻辑、微商是卖人逻辑；直营利润 20%–40%，OEM 贴牌可到 200%+；直营后端常用虚拟人设是弱点（参考 RZP-037 RZP-039 RZP-034）；直营化私域体系的特征是前端强后端弱（约 80% 团队偏重前端获客，只有 10%–20% 后端做得好）、选品偏好不需要教育的标品（复刻表/包/鞋类）、供应链走一件代发不囤货，前后端团队物理隔离防止自立门户，利润结构是中间差价全部留公司自己分配（参考 RZP-029 RZP-030 RZP-031 RZP-032 RZP-033）；判断直销/代理体系健不健康只看一条——C 端零售是不是真实跑得动，只做 B 端拉人头、靠画饼招商不可持续（参考 XY-DY-062） |
| 红线 | 食品不得宣传功效、团队计酬税务、代理级别（参考 MSP-015）；直销三前提（参考 XY-DY-251）；先查同类项目历史处罚（参考 XY-DY-144） |
| 账号结构（脱敏） | 前端 IP/直播打流量 + 后端专业老师服务的直营盘；或"直营 + 招商"两条腿（参考 XY-DY-177） |
| 典型死法 | 前后端脱节；把 GMV 当利润；无资质讲疗效；裂变前没有 100–500 个种子用户就搞活动（参考 XY-DY-273） |
