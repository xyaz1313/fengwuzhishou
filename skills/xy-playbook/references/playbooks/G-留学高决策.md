#### 模板 G：留学 / 高决策成本非标服务（家庭决策、投入巨大、必须一对一）

| 维度 | 打法 |
|---|---|
| 关键卡点 | C→D 信任；留学是家庭决策且投入巨大，用户动念后一定翻你账号判断可不可信（参考 XY-MA-1302 XY-MA-1303） |
| 内容职能 | 种草：探校街采、猎奇案例分析、毒舌吐槽——不做求学吐槽/国外热点/留子生活趣事，那些吸引的是吃瓜群众和已在国外的人（参考 XY-MA-1315 XY-MA-1313）；专业：项目圈人群、一手/二手信息、认知视野、案例分析四类（参考 XY-MA-1322 XY-MA-1323）；信任：情感牌（自我暴露、教育责任感、公开树敌黑中介）+ 认知牌（明确责任主体、展示交付流程与案例）（参考 XY-MA-1325 XY-MA-1326） |
| 选题来源 | 用户决策七阶段：动念→认知加固→目标选定→背景研究→信息补全→申请攻略→信任积累，每阶段一组选题（参考 XY-MA-1328） |
| 产品分层 | 引流品 0–100 元咨询/免费申请；核心品 500–1000 元规划 + 3 千–8 万元陪跑；增值品 2–5 万元考团训练营；关联品 200–3 千元介绍信/实习/申诉（参考 XY-MA-1292） |
| 获客导流 | 埋钩子（免费咨询）、固定直播连麦答疑、投稿回应视频；每条结尾固定一句引导语（参考 XY-MA-1294 XY-MA-1338 XY-MA-332） |
| 成交场景 | 私域 1v1 五步：免费品进私域→朋友圈案例攒信任→先让用户自我暴露再答疑引出付费品→用截止日/名额制造紧迫→成交后推增值品（参考 XY-MA-1297 XY-MA-1339）；有问才有答，报价资历不主动发（参考 XY-MA-1340） |
| 红线 | 教育宣传与承诺性表述；揭黑内容不点名具体机构；查证路径见 2e |
| 账号结构（脱敏） | ①"说真话/揭黑"型：承认非名校出身，持续批评水校黑中介反向锚定可信度，免费申请靠渠道返点并公开说明怎么赚钱，服务消费型用户，据案例描述一年涨粉约 8.4 万、专业类线索率最高约 10%（数字出处 XY-MA-1431；定性参考 XY-MA-1430 XY-MA-1433 XY-MA-1434）；②"在场感"型：本人探校街采拿一手信息，街采涨粉、口播获客双线并行，据案例描述口播线索率 10%–15%（参考 XY-MA-1441 XY-MA-1442）；③"猎奇案例分析"型：专业性足够强、做顶级院校高客单的人才配得上（参考 XY-MA-1342） |
| 典型死法 | 只做流量不设钩子，用户"三过家门而不入"（参考 XY-MA-1304）；抄头部的哗众取宠（参考 XY-MA-1299） |
