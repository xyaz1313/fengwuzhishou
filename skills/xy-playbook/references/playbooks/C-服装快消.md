#### 模板 C：服装 / 穿搭 / 不需要教育的快消（一看就懂、比价成交）

| 维度 | 打法 |
|---|---|
| 关键卡点 | 触达与冲动，不是信任——服装、鞋包、水果、零食、茶酒这类**不需要教育**的品，客户一看就知道是什么，靠比价比优势就能成交（参考 XSP-016 XPP-001 XY-DY-141） |
| 适不适合你 | **适合先做前端**：新人没人脉没资源时，从不需要教育的品切入最快（参考 XSP-016 XY-DY-141）；属于"低客单高复购的共识型产品"（利润几十到 100 元），与需要教育的非共识品打法完全不同（参考 XY-DY-136） |
| 实体店叠加私域 | 这是 XY 材料里最实的一条路径：月租 5 万的服装店原本线下月销稳定 20 万，接入私域运营后可能提升到 40-50 万，**增量部分几乎不增加固定成本**，只多花一两个人工去私聊客户（数字出处 RZP-020b）；做法是进店客户加微信送小礼（进店的人本来就想买衣服，今天没中意不代表以后不中意），此后每次上新直接发给他，客户天天在你朋友圈里，信任是这么攒的 |
| 新人礼设计 | 送围巾、墨镜、饰品这类几块钱成本的东西就能把人拉进私域，几块钱一个粉特别值——因为转化当天就可能完成，例如客户来拿饰品，你顺势说今天有一件原价 399 的 T 恤特价只要 60 块，当天就把这个粉的获客成本赚回来（参考 XY-WZ2-002；另参考 XY-DY-178 的适用边界：这类无强服务体系的品不适用"新人礼跨越高客单"，只适用于把人拉进来做当天转化） |
| 获客导流 | 平台分工：小红书是年轻到中年女性主场（美妆/减脂/服装），抖音算法最垂直是主力入口，视频号适合中老年（参考 LLP-002）；找对标要找**粉丝画像垂直**的账号，不是找同品类账号——你卖零食也可以去卖服装的账号底下捞粉，你要的是这批人不是他们买什么；用巨量算数核查候选账号的粉丝画像（年龄/性别/地区）再投放（参考 IPP-015 IPP-016） |
| 成交场景 | 当场下单为主；**退货是这个赛道的大坑也是私域的机会**——公域直播卖女装退货率可能高达 87%-99%，把这批退货客户导入私域做穿搭顾问式服务，客户即使退了公域的货，也可能在私域重新下单（参考 XY-DY-088） |
| 升单方式 | 卖整体解决方案而不是单件——像形象搭配师推荐整套穿搭，比单件讲参数更容易成交，这个逻辑适用于所有行业（参考 XY-DY-227） |
| 洗粉 | 品类跨度大了要洗粉：卖女鞋的号突然卖护肤，客户会觉得你不垂直、不专业，应该把人洗到另一个号（都是你自己的号，换新人设）——判断标准是「新产品与老账号赛道是否同源」：同源直接在原账号加 SKU，不同源才洗；洗的做法是朋友圈每 5-7 天提一次 + 发钩子（免费体验装/员工价）（参考 SCP-041） |
| 红线 | 面料/功效虚假描述；广告法用语（参考 XY-MB-322） |
| 典型死法 | 先起号攒粉再卖货；账面 GMV 好看年底不赚钱——退货率、投放、库存、团队层层叠加（参考 XY-MA-1395 XY-MA-1396）；SKU 太杂客户觉得你不专业（见洗粉一栏） |
