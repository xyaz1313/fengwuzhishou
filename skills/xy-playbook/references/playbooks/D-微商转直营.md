#### 模板 D：微商团队转直营 / 代理制改造（模式转型，不是行业）

这一张不是"某个行业怎么打"，是"你已经有一套体系，要不要换、怎么换"。XY 材料里这一块最厚。

| 维度 | 打法 |
|---|---|
| 先定性：你现在是哪一种 | **直营化**特征：偏前端流量思维（约 80% 团队重前端获客，只有 10%-20% 后端做得好）、选不需要教育的品（复刻表/包/鞋）、供应链一件代发不囤货、前后端团队物理隔离防自立门户、中间差价全部留公司分配（参考 RZP-029 RZP-030 RZP-031 RZP-032 RZP-033）。**微商化**特征：偏后端（代理主体多是宝妈等不具备互联网获客能力的人，从自己微信存量的同学同事开始）、选需要教育+需要重信任的品（精油/中医养生减脂/私护）（参考 RZP-035 RZP-036） |
| 根本区别 | 直营是**卖货逻辑**（产品性价比驱动，不依赖人设），微商是**卖人逻辑**（客户先信这个人才买他推荐的东西，进而持续复购）（参考 RZP-037） |
| 利润结构 | 直营团队正常利润空间只有 20%-40%，很难到 50%；微商化走 OEM 贴牌，利润空间可达 200%-300%+（20 元成本卖 299-399 元）（数字出处 RZP-039）——**这是很多人想从直营转微商化的真实动机，但代价是对信任和服务的要求高一个量级** |
| 直营的弱点 | 后端人设常用虚拟形象（不露脸的头像），除非真实 IP 出镜，否则很难在朋友圈建立深度信任（参考 RZP-034） |
| 分岔点在三转之后 | 直营体系三转后继续做复购升单（如到 5-6 千）；经销体系从三转开始往"大 b"方向发展下线（参考 MSP-004） |
| 经销商体系怎么设 | 五个核心激励要素：差价、同级奖金、团队管理奖、目标对赌奖励、股东分红，每一个都要想清楚不是照抄模板（参考 MSP-006）；同级奖金可设阶梯递增（早期招募奖励更高刺激起步）；对赌涨幅控制在 15%-20%，定得过高（直接翻倍）会让人放弃冲刺（参考 MSP-010 MSP-013）；顶层要留无限上升空间，预留隐藏级别（参考 MSP-007 MSP-020） |
| 操盘手要做两件事 | **赋能**（陪跑培训，按新人/中级/高级三阶段循序教零售、引流动销、招商团队管理）和**帮扶**（公司资源直接带经销商执行拿结果，如统一组织的裂变营/动销活动/招商会）（参考 CPP-044） |
| 健不健康只看一条 | C 端零售是不是真实跑得动——只做 B 端拉人头、靠画饼招商不可持续（参考 XY-DY-062）；判断品牌健康度看货物周转率而非回款金额，一年只周转 1-1.5 次意味着大量收款可能是可退的预售（参考 CPP-036） |
| 博弈结构自检 | 这套分钱是一次性还是重复关系？"人人自利"推演会稳在哪？承诺（返点/晋升）有没有绑代价？详见 `xy-mode` 2c（参考 XY-BK-001 XY-BK-003 XY-BK-005） |
| 红线 | 团队计酬税务、代理级别层数、食品功效（参考 MSP-015）；直销三前提——品牌方是否依法代扣个税、企业是否持有直销牌照、个人能否靠自己的 IP/直播获取流量而不只拉人头（参考 XY-DY-251 XY-DY-159） |
| 典型死法 | 把 C 端或小 B 客户流量直接分给下级代理（几乎必然导致代理背叛、客户流失）；用"被动收入"画饼（100 个代理货卖不出去，团队大不等于有被动收入）（参考 XY-DY-250）；只做 B 端不做 C 端 |
