#### 模板 B：中医养生 / 精油 / 私护（需要教育最重、非共识品）

| 维度 | 打法 |
|---|---|
| 关键卡点 | 教育——这类品市面罕见、客户不知道是什么，**必须先通过教育让人理解才谈得上购买**（参考 XPP-001）；电商完成不了人与人之间的教育，所以纯电商卖不好（参考 XY-DY-271） |
| 体系选择 | 这类品对信任要求极高（私密/入口类），属于典型的**微商化体系**适配品——靠"卖人逻辑"而非"卖货逻辑"（参考 RZP-036 RZP-037）；需要教育的产品更适合先靠微商/直销团队做 2-3 年市场教育，等市场有认知后再回捞直营逻辑会轻松很多，直接上直营很难成交（参考 XPP-003） |
| 为什么值钱 | 非标品定价权在自己手上，不会被电商比价压死利润（参考 XY-DY-085）；选项目要看产品背后有没有知识体系/服务价值——传统保健品（维C/益生菌）信息差已抹平难盈利，中医养生背后有知识体系所以还有空间（参考 XY-DY-160） |
| 教育节奏 | 千人一方先打开市场做认知，信任建立后再过渡到高客单一人一方（参考 XY-DY-270）；一级类目只能做曝光，成交要细到四五级类目（参考 XY-DY-156） |
| 产品分层 | 参照模板 A 的每转设计；这类品尤其要注意前端货盘与后端货盘按同一套"问题→方案"强关联（参考 XY-DY-025） |
| 内容职能 | 垂直选题可占 70% 甚至更高（参考 XY-MA-133）；无资质不讲功效，只做科普和个人经验分享（参考 XY-MA-1255） |
| 后端延展 | 与模板 A 同——课程、认证培训、家庭医生式年度服务，延展收入可能超过产品本身（参考 XPP-018） |
| 红线 | 医疗/功效表述是这个赛道最容易踩的线；无资质讲医疗、夸大疗效属广告法层面红线，只能转科普或个人经验（参考 XY-MA-1255 XY-MA-111）；食品不得宣传功效（参考 MSP-015） |
| 典型死法 | 跳过教育直接卖高客单；用直营的打法做需要教育的品（参考 XPP-003）；无资质讲疗效 |
