#### 模板 A：减脂 / 体重管理（需要教育 + 需要重信任 + 7 天可见效）

| 维度 | 打法 |
|---|---|
| 关键卡点 | 信任——这类品客户要吃进嘴里、要看身体反应，没有信任不会买；但它有个别的赛道没有的优势：**7-15 天就能让客户感受到效果**，信任可以靠结果快速兑现（参考 RZP-036 XY-DY-273） |
| 适不适合你 | 属于"高利润 + 需要教育 + 需要重服务"那一类，服务过程本身建立信任带来复购，**适合先做后端**（参考 XSP-019）；市场是轮回的，减脂品基本每两三年会有新品牌爆火一轮，不是一次性机会（参考 XPP-005） |
| 用户画像 | 从产品反推：23-40 岁爱美女性，内容围绕饮食搭配和掉秤效果（参考 XSP-009）；平台上小红书是这批人的主场（参考 LLP-002） |
| 产品分层（每转设计） | 一转 68/88/99 元 7 天体验装（7 天可见效如掉秤）→ 二转 598/698 元一个月套餐、总价不超 800 元 → 三转 2000-3000 元季度量 → 四转 9800-1 万（小 b 升大 b）（参考 RZP-027 MSP-002 XSP-037）；每一转的本质不是金额升级，是**延长与客户共处的时间、加深服务信任**（参考 XSP-037） |
| 一转怎么设 | 100 元以内、7 天量、能自观测的指标（入睡/掉秤/围度）；不要做 9.9 元级别的引流课或资料——低价用户和高客单用户不是同一批人，低转高转化率只有 2%-5%（参考 XY-DY-183 XY-DY-217） |
| 服务与社群 | 一转卖完后两种模式：建大群靠正反馈氛围（有人晒掉秤效果带动跟风），或一对一小队服务（1 个客户配 3-4 个专业老师，营造高专业感）（参考 MSP-003）；后端有专业老师做服务是复购的根，复购率可达 70%-85%（参考 LLP-008 LLP-038） |
| 获客导流 | 订单粉优先——前端下单用户进私域做复购与深度服务（参考 XY-DY-093 XY-DY-084）；"新人礼"解决 99-299 元到 3000-10000 元的跳级脱节，**只适用于带强服务体系的实体品**，减脂/大健康适用（参考 XY-DY-178） |
| 裂变时机 | 先有 100-500 个种子用户（代理或真实好评用户）再做裂变，周期 1-2 个月一轮；7-15 天能见效的品才适合这么裂（参考 XY-DY-273） |
| 后端延展 | 这类赛道自带知识付费延展性——除了卖产品还能卖课程、卖认证培训、卖家庭医生式年度健康服务，后端延展收入可能远超前端产品（参考 XPP-018） |
| 红线 | 食品不得宣传功效、不得承诺疗效与掉秤斤数；团队计酬税务、代理级别（参考 MSP-015 XY-MA-1255）；先查同类项目历史处罚（参考 XY-DY-144） |
| 典型死法 | 把 GMV 当利润；前端卖完没有后端服务承接（这类品全靠服务撑复购）；无资质讲功效；种子用户不够就搞裂变（参考 XY-DY-273） |
